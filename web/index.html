Connect. Flash. Speak.

Use desktop Chrome or Edge and a USB data cable. No development tools required.

  1. Connect the board’s USB-to-UART port to your computer.
  2. Close any serial terminal using the board.
  3. Connect below, select the board’s serial port, then choose Install VVVC.

Check your board

Supports ESP32, ESP32-C3, ESP32-S2 and ESP32-S3 with at least 4 MB flash and the pins below available. Every build provides GPIO PWM audio for an external filter and amplifier.

The original ESP32 Audio-Kit also plays through its ES8388 speaker/headphone output when detected. AC101 codec output is not supported.

Installation replaces the existing firmware. Resetting the board clears all learned phrase slots.

02 / HEAR IT WORK

Your first words

After installation, the board restarts and plays its startup sound on GPIO PWM and any detected ES8388. Use the Audio-Kit's labelled speaker terminals, or connect the PWM pin through a filter to an external amplifier. In the installer, open Logs & Console (115200 baud), type a line and send it.

Run the demo

-demo

A one-shot audio and speech test.

Say something

Hello from my VIC

English text becomes SC-01 speech.

Teach a phrase

-learn 1 text Hello there-play 1

80 shared slots. Teach them again after a reset.

The VIC serial input accepts these commands too. USB uses 115200 baud; the VIC connection defaults to 2400 baud. Speech is an approximation of the SC-01.

Need a hand?

The board doesn’t appear or won’t connect

Check that the cable carries data and uses the USB-to-UART connector. Close other serial programs. If the installer stays on “Connecting”, hold BOOT while connecting, then release it once flashing begins. A missing serial port may require the USB bridge manufacturer’s driver.

Run the local installer

This page can flash directly from Chrome or Edge. To use the installer offline, download the installer ZIP, extract it, then double-click start-local.bat on Windows. This requires Python 3. Open http://localhost:8765 in Chrome or Edge and leave the launcher window open while flashing. Do not open index.html directly from a drive.

GPIO audio wiring

ESP32: GPIO22. C3/S2/S3: GPIO4. The signal is 8-bit PWM with a 156.25 kHz carrier, idle at 50% duty. It needs a low-pass filter, DC-blocking capacitor and amplifier. Never connect a speaker or headphones directly to a GPIO.

PWM -- 1k --+-- 4.7k --+-- 1uF film -- amplifier input
           |         |
          22nF      4.7nF
           |         |
GND -------+---------+-------------- amplifier ground

Use a high-impedance amplifier input (47 kOhm or greater), short wires and low initial volume. Check your board schematic for pin conflicts. The GPIO and codec carry the same sound with independent buffering, so they are not phase-aligned.

VIC UART RX/TX: GPIO18/5 on ESP32; GPIO6/7 on C3/S2/S3. The VIC transmit line still needs 5 V to 3.3 V level conversion. On the classic ESP32, GPIO33/32 are reserved for codec detection.
