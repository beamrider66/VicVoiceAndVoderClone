01 / INSTALL

Connect. Flash. Speak.

Use desktop Chrome or Edge and a USB data cable. No development tools required.

  1. Connect the board’s USB-to-UART port to your computer.
  2. Close any serial terminal using the board.
  3. Connect below, select the board’s serial port, then choose Install VVVC.

Check your board

This firmware needs a classic ESP32 Audio-Kit with an ES8388 codec and 4 MB flash. AC101 boards, bare DevKits and ESP32-S2/S3/C3 boards are not compatible.

Installation replaces the existing firmware. Resetting the board clears all learned phrase slots.

Loading the installer…
Use desktop Chrome or Edge with Web Serial support. Open this page over HTTPS to connect to your board.

The installer checks the ESP32 chip family; it cannot identify your audio codec. Check the ES8388 marking before installing.

02 / HEAR IT WORK

Your first words

After installation, the board restarts and plays its startup sound. Connect a speaker to the labelled speaker terminals. In the installer, open Logs & Console (115200 baud), type a line and send it.

Run the demo

-demo

A one-shot audio and speech test.

Say something

Hello from my VIC

English text becomes SC-01 speech.

Teach a phrase

-learn 1 text Hello there-play 1

80 shared slots. Teach them again after a reset.

The VIC serial input accepts these commands too. USB uses 115200 baud; the VIC connection defaults to 2400 baud. Speech is an approximation of the SC-01.

Need a hand?

The board doesn’t appear or won’t connect

Check that the cable carries data and uses the USB-to-UART connector. Close other serial programs. If the installer stays on “Connecting”, hold BOOT while connecting, then release it once flashing begins. A missing serial port may require the USB bridge manufacturer’s driver.

Use a local copy or troubleshoot HTTPS

This HTTPS site can flash directly from Chrome or Edge. For a local copy, download the installer ZIP, extract it, then double-click start-local.bat on Windows. This requires Python 3. Open http://localhost:8765 in Chrome or Edge and leave the launcher window open while flashing. Do not open index.html directly from a drive.

Browsers need HTTPS with a trusted certificate or localhost to access USB serial ports. An ordinary HTTP website can provide downloads, but cannot connect to your board.
